# ماسح المستندات — Python + صفحة ويب

برنامج بايثون بيفتح صفحة ويب عندك فيها زر **سكان**. بيتصل بالسكانر عن طريق **USB**، وإذا ما لقاه بيدوّر عليه بالـ**شبكة المحلية**. بتشوف الصفحات وهي عم تنقرأ، بتحدد أو بتشيل التحديد عن أي صفحة، وبتضغط **تحويل إلى PDF**، وبتحفظ الملف عالـ **سطح المكتب**.

> **للتضمين بتطبيق Flutter (iframe / WebView2) والتغليف كـ exe:** شوف `INTEGRATION.md`.

## التشغيل (ويندوز)

1. ثبّت Python 3.10 أو أحدث من python.org (علّم خيار **Add python.exe to PATH**).
2. دبل كليك على **`run.bat`**. أول مرة بينزّل المكتبات لحاله (بدو إنترنت).
3. بيفتح المتصفح على `http://127.0.0.1:5000`. **خلّي النافذة السودا مفتوحة** طول ما بتسكان.

الواجهة بألوان الهوية البصرية السورية (أخضر عميق #042623، ذهبي #B9A779، أخضر العلم #008000، أحمر #CE1126).

بدك تجرّب الواجهة بدون سكانر؟ شغّل `run.bat --demo` (سكانر وهمي).

## كيف بيشتغل زر «سكان»

1. **USB**: أول شي بيجرّب **WIA** (مبني بويندوز وبيشتغل مع أغلب الدرايفرات). إذا ما لقى، بيجرّب **TWAIN** (بيتثبّت تلقائياً من `run.bat`، وإذا فشل بيكمّل بدونو).
2. **الشبكة**: إذا ما لقى USB (أو فشل الاتصال)، بيدوّر بالشبكة عن طريق **eSCL / AirScan** (HP, Canon, Epson, Brother وغيرها من بعد 2015 تقريباً). بيلاقي السكانر لحاله بـ mDNS، أو بتكتب عنوان الـ IP بالإعدادات.
3. الصفحة بتعرض رسالة التقدّم («عم دوّر…»، «جاري قراءة الصفحة 2…») وكل صفحة بتظهر مصغّرة أول ما تنقرأ.

### الإعدادات
- **الاتصال**: تلقائي / USB فقط / الشبكة فقط
- **الدقة**: 150 – 600 dpi (300 موصى فيه للمستندات)
- **الألوان**: ملوّن / رمادي / أبيض وأسود
- **مصدر الورق**: السطح الزجاجي (ورقة ورقة، اضغط سكان لكل ورقة وبتنضاف) أو التغذية التلقائية feeder (كل الأوراق مرة وحدة)
- **عنوان IP**: للسكانر الشبكي إذا ما انلقى لحاله، مثل `192.168.1.50`
- **فحص الأجهزة**: بيعرض شو لقى البرنامج وشو ناقص عندك. استعملو أول شي إذا في مشكلة.

### بعد السكان
تحديد الكل / إلغاء التحديد، **تدوير** 90°، حذف المحدد، مسح الكل، وضغطة على الصورة بتكبّرها. زر **تحويل إلى PDF** بيعمل ملف بس من الصفحات المحددة (بنفس ترتيبها)، وبعدها: **تنزيل الملف** أو **حفظ على سطح المكتب**.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| «ما لقيت أي سكانر» | افتح «فحص الأجهزة». تأكد إنو السكانر شغّال، وإنو بيظهر ببرنامج **Windows Scan** أو **Fax and Scan**. إذا بيظهر هناك بس مو هون، ابعتلي نص «فحص الأجهزة». |
| «مكتبة pywin32 مو مثبتة» | شغّل `run.bat` من جديد (بيثبّتها)، أو: `.venv\Scripts\pip install pywin32` |
| السكانر ما بيطلع بـ WIA بس عندو TWAIN | `.venv\Scripts\pip install -r requirements-twain.txt` وجرّب. **انتبه:** درايفر TWAIN 32-bit بدو Python 32-bit. |
| السكانر الشبكي ما انلقى | لازم يكون الكمبيوتر والسكانر عالشبكة نفسها. اكتب الـ IP بالإعدادات. تأكد إنو الـ Firewall ما عم يمنع Python (mDNS = UDP 5353). السكانرات القديمة اللي ما بتدعم eSCL ما بتشتغل بالشبكة، استعمل USB. |
| «ما في ورق بالـ feeder» | حط الأوراق، أو اختار «السطح الزجاجي» من الإعدادات. |
| زر الإلغاء | بيوقف قبل الصفحة الجاية. الصفحة اللي عم تنقرأ بتكمّل. |

## هيكل المشروع

```
app.py                  السيرفر المحلي + الـ API
service_main.py         الخدمة بالخلفية (tray + تشغيل مع ويندوز)
packaging/              PyInstaller + Inno Setup (مثبّت الموظفين)
static/                 صفحة الويب (index.html, style.css, app.js)
scanner/
  wia_backend.py        USB عبر WIA (pywin32)
  twain_backend.py      USB عبر TWAIN (اختياري)
  escl_backend.py       الشبكة عبر eSCL + mDNS
  demo_backend.py       سكانر وهمي للتجربة
  manager.py            ترتيب البحث: USB ثم الشبكة
  jobs.py               مهمة السكان + التقدّم
  store.py              حفظ الصفحات وبناء الـ PDF وحفظه عالسطح
tests/                  الاختبارات
```

## ملاحظات

- **الخصوصية:** السيرفر بيسمع على `127.0.0.1` فقط (مو متاح من الشبكة) وبيرفض الطلبات من مواقع ثانية. الصفحات الممسوحة بتنحفظ مؤقتاً بمجلد `data/` وبتنمسح كل ما تشغّل البرنامج.
- **مرجع Flutter / Dynamsoft:** هالمشروع ما بيستعمل Flutter ولا Dynamsoft (هداك SDK تجاري بيحتاج مفتاح ترخيص). بدالو استعملنا WIA / TWAIN / eSCL المجانيين مع Python.
- **حالة الاختبار:** منطق البرنامج، الـ API، الواجهة (بمتصفح حقيقي)، بناء الـ PDF، وبروتوكول eSCL (ضد سكانر وهمي) انفحصوا. أما **WIA وTWAIN** فانفحصوا بمحاكاة بس، لأنو ما كان في ويندوز ولا سكانر حقيقي. ممكن بعض الدرايفرات تتصرف باختلاف؛ وقتها «فحص الأجهزة» والرسالة اللي بتظهر بتساعدونا نصلّح.
